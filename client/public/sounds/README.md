# Sound effects (MP3)

Drop one MP3 per file below. The app loads them from `/sounds/<name>.mp3`. **Missing files are skipped silently** — add files when ready and they start playing automatically (with sound effects enabled in Your preferences).

| File | Used for |
|------|----------|
| `ui-click.mp3` | Optional UI feedback |
| `ui-error.mp3` | Join / room errors |
| `success-small.mp3` | Join success, correct guess |
| `round-start.mp3` | Round started |
| `clue-reveal.mp3` | Clue revealed |
| `round-end.mp3` | Round ended |
| `game-win.mp3` | Game ended |
| `card-flip.mp3` | In-person answer reveal |
